# SomEdSer releases

Desktop installers for SomEdSer. Download the latest from the [releases page](https://github.com/BadramaTech/somedser-releases/releases/latest):

- Windows: `SomEdSer-Setup.exe`
- Mac (Apple silicon): `SomEdSer.dmg`

The app updates itself from here. Source and issues live in the main SomEdSer repository.
